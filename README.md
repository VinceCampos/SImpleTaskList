# Simple Task List

A simple and user-friendly Task List application built using **HTML, CSS, and JavaScript**. This project allows users to organize their daily activities by adding tasks, marking them as completed, and removing tasks when they are no longer needed.

## Features

- **Add Tasks** – Create new tasks by entering a task name.
- **Enter Key Support** – Add tasks by pressing the Enter key.
- **Mark as Completed** – Check tasks once they are finished.
- **Delete Tasks** – Remove tasks from the list.
- **Simple Interface** – Clean and straightforward user interface.

## Built With

- **HTML5** – Provides the structure of the application.
- **CSS** – Handles the styling and layout.
- **JavaScript** – Implements the task management functionality and user interactions.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your preferred web browser.
4. Start adding and managing your tasks!
